# Introduccion-a-flexbox
Aprendiendo desde 0 que es y como se utiliza el flexbox

### En esta actividad logré dominar estas herramientas de CSS:
display: flex: Para convertir mis secciones en contenedores inteligentes.
justify-content: Lo usé para separar el logo de los botones en el menú (como se ve en la página real de Starbucks).
flex-direction: row-reverse: Con esto hice el efecto de "zig-zag" donde una imagen va a la derecha y en la siguiente sección va a la izquierda.
align-items: center: Para que todos los textos y botones queden perfectamente centrados verticalmente.

## Estructura del proyecto
Siguiendo los consejos de la clase, dividí mi código en estas secciones:
Header: Barra de navegación con logo y botones.
Hero: Banner principal con el color verde clásico.
Cards: Secciones de promociones con imágenes.
Footer: Pie de página con créditos.
